# 🚀 AI/ML Project Portfolio

Welcome to my **AI/ML Project Portfolio** — a collection of real-world applications built using **Machine Learning, Deep Learning, and Computer Vision**.

Each project is independently designed, developed, and deployed as a **production-ready Streamlit app**.

---

## 🌟 Highlights

* ✅ Multiple end-to-end AI applications
* ✅ Real-time prediction systems
* ✅ Clean UI using Streamlit
* ✅ Modular architecture (each project independent)
* ✅ Deployment-ready (Streamlit Cloud / Hugging Face)

---

## 📂 Projects Overview

| Project                                   | Description                                                  | Tech Stack          | 
| ----------------------------------------- | ------------------------------------------------------------ | ------------------- | 
| 🧓 **Senior Citizen Detection**           | Detects age, gender & identifies senior citizens from images | TensorFlow, OpenCV  |
| 🌍 **Nationality Detector (Logic-Based)** | Face attribute analysis with rule-based region estimation    | OpenCV, NumPy       |
| 🤟 **Sign Language Detection**            | Rule-based hand gesture classification system                | OpenCV, NumPy       |
| 🎙️ **Voice Age Detection**               | Predicts age group from voice (male-only logic)              | TensorFlow, Librosa | 
| 🚗 **Car Color Detection**                | Detects vehicle color using object detection                 | YOLO, OpenCV        |
| 👥 **People Count Detection**             | Counts number of people in image/video                       | YOLO (Ultralytics)  |

---

## 🧠 Architecture Strategy

Instead of combining everything into one heavy system, each project is:

* 🔹 **Independently deployed**
* 🔹 Uses its own dependencies
* 🔹 Optimized for performance
* 🔹 Easier to debug & scale

This follows **real-world production architecture practices**.
