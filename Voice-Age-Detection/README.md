# 🎙️ Voice-based Age Detection (Male-only)

## 📌 Overview
This project predicts **age group from voice input** using deep learning.

⚠️ Note: This system processes **male voices only** as per task requirements.

---

## 🚀 Features
- 🎧 Audio upload support
- 🧠 Gender detection + Age prediction
- 📊 Age group classification
- 😊 Emotion detection for senior citizens

---

## 🧠 Model Details
- Gender Model: Binary Classification (Male/Female)
- Age Model: Regression → Age Group Mapping
- Feature Extraction: MFCC (Librosa)

---

## 🛠️ Tech Stack
- Python
- Streamlit
- Librosa
- TensorFlow / Keras

---

---

## ⚠️ Limitations
- Works best with clean audio
- Designed for male voices only
