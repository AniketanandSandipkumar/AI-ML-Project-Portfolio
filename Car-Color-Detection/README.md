🚗 Car Color Detection & 👥 People Counter

---
📌 Overview
This project detects:
- 🚘 Car colors
- 👥 Number of people in image

using Computer Vision + YOLO.

---

🚀 Features
- 🖼️ Image upload
- 🎯 Object detection (YOLO)
- 🎨 Car color classification
- 👥 People counting

---

🧠 Model Details
- YOLOv8 (Ultralytics)
- OpenCV for processing
- Color detection using pixel clustering

---

🛠️ Tech Stack
- Python
- Streamlit
- OpenCV
- Ultralytics YOLO
- NumPy
